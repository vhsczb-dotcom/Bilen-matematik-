ÖYKÜ MATEMATİK - DOĞAL YAPAY ZEKÂ SESLİ SÜRÜM

Bu paket tek bir web servisi olarak çalışır.
- public/index.html: uygulama
- server.js: doğal yapay zekâ sesi için güvenli sunucu
- package.json: Node.js bağımlılıkları
- public/manifest.json + sw.js: telefonda uygulama gibi kullanım

Gerekli gizli ortam değişkeni:
OPENAI_API_KEY = kendi OpenAI API anahtarınız

İsteğe bağlı:
OPENAI_TTS_VOICE = marin

İsteğe bağlı:
OPENAI_TTS_MODEL = gpt-realtime-2.1-mini
